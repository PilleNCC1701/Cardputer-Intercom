# Cardputer-Intercom for M5Stack Cardputer and M5Stack Cardputer ADV
Wifi is not necessary. The firmware is uses ESP Now.
You have to use older board version (M5Stack 3.2.1) . With the newer version of M5Stack by M5Stack the is no sound.
It´s a communication system with chat and audio. The files are getting stored on the micro sd card (up to 64gb, in my case 128gb is not working).
